# Data

This folder holds the datasets and all files generated during data preparation. Apart from this README and the cached species file, everything in here is downloaded or generated by the scripts and is not part of the repository.

The models are trained on InsectSet459. The impulse responses are only used for data augmentation.

| Dataset | Source | License | Download |
|---|---|---|---|
| InsectSet459 | [Zenodo](https://zenodo.org/records/15675220) | see Zenodo record | `./scripts/download_IS459.sh` |
| Impulse responses | [OpenAIR](https://www.openair.hosted.york.ac.uk/) | see OpenAIR | `./scripts/download_IRs.sh` |

The impulse responses are the same as those used by [InsectEffNet](https://github.com/danstowell/insect_classifier_GDSC23_insecteffnet/tree/useIS459):
koli-national-park-summer, koli-national-park-winter, trollers-gill, tyndall-bruce-monument and gill-heads-mine.

## Data preparation steps

All scripts are run from the repository root and list their options with `-h`. Each step writes an annotation file (`annotations_*.csv`, one row per recording) and, where applicable, a label mapping (`label_mappings_*.yml`, class index to class name) into a `meta/` folder.

### 1. Collect metadata: `metadata_prep_insectset.py`

```bash
python src/data_prep/metadata_prep_insectset.py
```

Reads the InsectSet459 annotations and adds the path, audio properties (sample rate, duration, encoding, ...) and an MD5 hash of each recording. It writes `data/InsectSet/meta/` and registers the dataset in `data/aggregation/dataset_metadata.yml`, which lists the datasets to aggregate in the next step.

### 2. Aggregate: `aggregate_datasets.py`

```bash
python src/data_prep/aggregate_datasets.py
```

Combines all datasets listed in `data/aggregation/dataset_metadata.yml` (here only InsectSet459) into one annotation file and removes duplicate recordings (by hash and file name). Output: `data/aggregation/initial/`.

The species names are checked against the [Orthoptera Species File](https://orthoptera.speciesfile.org) and [Hoppers Species File](https://hoppers.speciesfile.org). The script downloads the current species lists. If the download fails, or with `--no-download`, it uses the cached copy in `data/aggregation/species_file/cached_species_file_simple.csv`.

Species names that are not found in the species files are listed in `data/aggregation/initial/species_name_mapping.xlsx`. By default they are kept unchanged. With `--no-keep-classnames`, the column `user_mapping` is left empty instead, and you can fill it in to rename a class (enter the new name) or drop it (leave it empty). For InsectSet459 this step is not needed.

The script stops if `species_name_mapping.xlsx` exists already, so that a manually edited mapping is not overwritten. Delete or rename it to run the script again.

### 3. Filter: `filter_aggregation.py`

```bash
python src/data_prep/filter_aggregation.py --filter-config-path configs/dataset_filtering/initial_training.yml
```

Applies the species name mapping from step 2 and the filters in the given config. `initial_training.yml` removes recordings with a sample rate below 44.1 kHz and classes with fewer than 3 training, 2 validation or 1 test recording. The output folder is named after the config file: `data/aggregation/filtered/initial_training/`.

Without `--filter-config-path`, only the mapping is applied and the output is written to `data/aggregation/filtered/no_filters/`.

### 4. Resample: `resample_audio.py`

```bash
python src/data_prep/resample_audio.py \
    -a ./data/aggregation/filtered/initial_training/meta/annotations_initial_training.csv \
    --target-sample-rate 48000 --max-workers 6 \
    --output-dir ./data/aggregation/resampled_files/
```

Resamples all recordings to 48 kHz and stores them as WAV files in `data/aggregation/resampled_files/files/` (~72 GB). By default, a librosa-style `kaiser_best` resampling (via `torchaudio.transforms.Resample`) is used; see `--resampling-method` for alternatives.

`data/aggregation/resampled_files/meta/annotations_resampled.csv` is the annotation file used for training (24,950 recordings, 451 classes). After this step the original recordings in `data/InsectSet/` can be deleted.
